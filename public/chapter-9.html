SECTION 2: SSID vs BSSID & EVIL TWIN DETECTION

🔑 SSID vs BSSID

Definition: SSID is the network name; BSSID is the MAC address of the specific access point radio.

Comparison Table:

FeatureSSIDBSSID
Full FormService Set IdentifierBasic Service Set Identifier
PurposeIdentifies a WLAN by nameIdentifies a specific Basic Service Set
FormatText string (e.g., ADU)48-bit MAC-format address
UniquenessMultiple APs may share the SSIDEach BSS normally has a distinct BSSID
VisibilityShown in available Wi-Fi networksShown by WLAN scanning tools
ExampleADU-WiFi00:11:22:33:44:01

Key Point:

  • One physical AP can have multiple BSSIDs across radios (2.4 GHz and 5 GHz) or virtual WLANs.

Diagram (SSID vs BSSID):

Memory Aid:

"SSID = The Name on the Door. BSSID = The Exact Apartment Number."

🔑 CASE STUDY: DETECTING AN EVIL TWIN AP

Scenario: A university operates a legitimate wireless network named ADU-WiFi. An attacker sets up a rogue access point with the same SSID to lure users, potentially offering a stronger signal and weaker security.

Wi-Fi Scanning Results:

SSIDBSSID (MAC)ChannelSignalSecurityVendorType
ADU00:11:22:33:44:016-65 dBmWPA2-EnterpriseCiscoLegitimate
ADU00:11:22:33:44:0236-70 dBmWPA2-EnterpriseCiscoLegitimate
ADU00:11:22:33:44:03149-68 dBmWPA2-EnterpriseCiscoLegitimate
ADUDE:AD:BE:44:55:666-35 dBmOpenUnknownSuspicious

Key Indicators to Investigate:

  1. Same SSID with unknown BSSID.
  1. Unexpectedly strong signal (e.g., -35 dBm vs -65 dBm).
  1. Weaker/different security settings (e.g., Open vs WPA2-Enterprise).
  1. Unrecognized vendor or AP location.

Important Verification Notes:

  • A different BSSID alone does NOT prove an Evil Twin.
  • Check authorized AP inventory and 802.1X settings.
  • Correlate signal, channel, location, and capabilities.

Memory Aid:

"Stronger signal + Open security + Unknown MAC = Evil Twin."
SECTION 3: PENETRATION TESTING TOOLS

🔑 PENETRATION TESTING

Definition: The practice of searching for and then attempting to exploit vulnerabilities on networks that an attacker could potentially exploit. In essence, pentesting is attacking the network with permission.

🔑 METASPLOIT FRAMEWORK

Definition: One of the most popular frameworks for pentesting. Used on a mature network to assess the state of defense.

Metasploit Architecture:

ComponentDescription
ModulesReusable building blocks: Exploit (takes advantage of a vulnerability), Auxiliary (scanners, fuzzers, bruteforcers, info-gathering), Payloads (code run on target), Post (post-exploitation tasks like credential collection), Encoders/nops (helpers for payload delivery).
InterfacesInteract via msfconsole (interactive), API, or scripted clients.
MeterpreterA widely used in-memory payload that gives an interactive shell-like session and post-exploit actions (file ops, process migration, port forwarding).
MsfvenomA utility to create payloads or shellcode.

Memory Aid:

"Modules = Exploit, Auxiliary, Payload, Post, Encoder. Interface = Console. Payload = Meterpreter. Generator = Msfvenom."

🔑 METASPLOIT 6-STEP PROCESS

StepActionDescription
1ReconnaissanceGather information: open ports, services, versions.
2Select ModuleChoose an appropriate module (scanner or exploit).
3ConfigureSet target hosts, ports, options, and payload.
4LaunchRun the module (exploit triggers vulnerability; auxiliary performs scan).
5Post-ExploitationIf session obtained (e.g., Meterpreter), enumerate system, gather evidence, assess lateral movement, then clean up.
6Report & RemediationRecord findings, provide remediation steps, verify fixes.

Memory Aid:

"Recon → Select → Configure → Launch → Post → Report."

🔑 METASPLOIT USE CASES

Use CaseDescription
1. Vulnerability Verification in a Patch TestScan patched and unpatched servers, run exploit, verify if exploitation is still possible, document results.
2. Network Service Discovery & AssessmentUse auxiliary scanners to enumerate hosts/services, identify versions, correlate to known vulnerable modules.
3. Post-Exploit AuditingRun post modules to enumerate software, dump password hashes, check weak configurations.
4. Exploit Development & ResearchWrite custom exploit modules (Ruby templates) to test new vulnerabilities.
5. Training / Red-Team ExercisesAuthorized scenarios to exercise detection and response of SOC teams.

🔑 SECURITY AUDITOR'S RESEARCH ASSISTANT (SARA)

Definition: Integrates with the National Vulnerabilities Database (NVD) and performs many pentests.

Key Features:

  • Integrates with Nmap (OS fingerprinting, remote network port scanning).
  • Performs SQL injection and cross-site scripting (XSS) tests.

Responsibilities:

  • Gathering/organizing threat & vulnerability research (CVEs, advisories).
  • Checking compliance (ISO, NIST, PCI-DSS).
  • Generating audit checklists, scoping, risk assessments.
  • Automating scan/vulnerability detection.
  • Preparing reports and suggesting mitigations.
  • Learning/training support.

Memory Aid:

"SARA = NVD + Nmap + Compliance + Reports."

🔑 PASSWORD CRACKING METHODS

Definition: Tools use two primary methods to crack passwords.

MethodHow It WorksAnalogy
Dictionary AttackEach item in a dictionary/word list is encrypted/hashed and compared to the original password's hash. If they match, the password is revealed.Trying every key on a keyring to open a lock.
Brute-Force AttackCompares all possible combinations of characters for a given password length.Trying every possible combination on a combination lock.

🔑 NETWORK ENUMERATORS

Definition: Software programs that scan the network for active hosts.

Key Points:

  • Uses discovery protocols: ICMP (Internet Control Message Protocol) and SNMP (Simple Network Management Protocol).
  • May scan TCP and UDP ports on remote hosts to identify services (banners).
  • Next stage: Fingerprinting the Operating System (e.g., Nessus, Nmap).

Memory Aid:

"Enumerate hosts → Scan ports → Fingerprint OS."

Quick Cue: ICMP and SNMP help discover hosts. Unix/Linux uses traceroute; Windows uses tracert.

🔑 NETWORK MANAGEMENT SYSTEM (NMS)

Definition: The foundation of network security. Provides a single viewpoint from which an administrator can view, plan, and configure the network.

Key Points:

  • Enables SNMP (Single Network Management Protocol) for monitoring and managing network devices.
  • Raises alerts and alarms via SNMP traps.

SNMP Trap: Sent from a network device to an SNMP management system without being solicited. Triggered when a specific event occurs (link down, auth failure, power failure).

Trap Message Contents:

  • Device and interface where the event occurred.
  • Time the event occurred.
  • Severity of the event.

📊 SNMP TRAPS (THE 6 TYPES)

Trap TypeWhen It's GeneratedWhat It's Used For
Cold StartDevice is powered on or restarted.Detect reboot; check configuration/status.
Warm StartDevice restarted without losing configuration.Detect reboot without config loss.
Link DownNetwork interface has gone down.Detect link failure; notify personnel.
Link UpNetwork interface has come up.Reconfigure routing tables.
Authentication FailureUser authentication attempt has failed.Block the user's IP address.
EGP Neighbor LossRouter loses an Exterior Gateway Protocol neighbor.Signal neighbor router is unavailable; update routing tables.

Memory Aid:

"Cold, Warm, Down, Up, Auth, EGP."

SECTION 7: ATTACK TOOLS AND TECHNIQUES

🔑 RADIO FREQUENCY JAMMING

Definition: A deliberate disruption of transmission.

Key Points:

  • Can block or censor radio broadcasts (usually at a border region).
  • Wireless 802.11 networks are very vulnerable to jamming.

Real-World Example:

Think of jamming like blasting a loud siren so no one can hear the radio.

🔑 DENIAL OF SERVICE (DoS)

Definition: Flooding the RF spectrum to jam a wireless network, or using more elegant methods to drop connections.

Key Points:

  • Flooding: One way to jam an 802.11 network.
  • Deauthentication packets: A more elegant way. Forces access points to deauthenticate and drop connections.
  • A script keeps injecting deauth requests → AP constantly authenticates and drops connections.

Real-World Example:

Think of deauth attacks like constantly pulling the plug on a connection, forcing it to restart.

🔑 HIJACKING DEVICES

Definition: Attacking devices that automatically attach to known networks.

How It Works:

  1. Windows clients automatically attempt to attach to any network to which it has previously been attached.
  1. It favors the access point with the highest transmit signal.
  1. Hackers create a rogue AP (evil twin) with high signal strength.
  1. Force a deauthentication.
  1. Client connects to the hacker's evil twin.

Real-World Example:

Think of hijacking like stealing a friend's identity at a party. Your phone thinks it's connecting to a familiar network, but it's really the attacker.

🔑 HIJACKING A SESSION

Definition: Another form of the man-in-the-middle attack.

Vulnerability Exploited:

  • HTTP is not session-oriented. It does not remember a user from one command to the next.
  • Web applications use session cookies to remember users.

📊 SESSION HIJACKING EXAMPLE (ALICE & CHARLIE)

The Flow:

StepWhoAction
1AliceLogs into http://www.example.com over plain HTTP (not HTTPS).
2ServerResponds with a session cookie: Set-Cookie: sessionid=Alpha999.
3AliceMakes a request to view dashboard: GET /dashboard with Cookie: sessionid=Alpha999.
4Charlie (Attacker)On the same open Wi-Fi, sniffs network traffic and reads the cookie Alpha999. Sends a request with Alice's cookie: GET /dashboard with Cookie: sessionid=Alpha999.
5ServerSees valid sessionid=Alpha999 and believes the request is from Alice. Charlie is logged in as Alice. Session hijacked.

Memory Aid:

"HTTP doesn't remember. Sniff the cookie, steal the session."
SECTION 8: COMMON WEBSITE VULNERABILITIES

🔑 COMMON WEBSITE VULNERABILITIES

Definition: Attackers exploit weaknesses in web applications to inject malicious code or steal data.

VulnerabilityDescriptionHow It Works
CRLF InjectionCarriage Return Line Feed (\r\n).Splits an HTTP packet into two: one with legitimate header info, one with malicious payload. ASCII code of \r is 13 (d in hex), \n is 10 (a in hex).
Malicious PayloadInjecting code via URL parameters.Example: http://example.com/search?q=test%0d%0aContent-Length:%200... Server decodes it as a new HTTP response with <h1>Hacked</h1>.
SQL InjectionInjecting SQL commands into input fields.Can steal, modify, or delete database data.
Cross-Site Scripting (XSS)Embedding malicious code that executes when a user performs a specific action.Steals cookies, redirects users, defaces websites. (Added detail)
JavaScript InjectionUsing JavaScript to modify existing info in webforms, input tags, or cookies.Can alter page behavior, steal data. (Added detail)

Memory Aid:

"CRLF, SQLi, XSS, JS Injection — the 4 web app villains."

✅ THE CORE TRUTH
WLAN auditing requires a toolkit: discovery tools (AirCheck, Ekahau) map the network, penetration tools (Metasploit, SARA) find vulnerabilities, password tools (Nessus, Aircrack-ng) crack weak credentials, management tools (NMS, SNMP) monitor health, and attack tools (jammers, deauth, hijacks) test resilience. Attackers exploit the same tools—so understanding them is the key to defense.
